# Third-party notices

The Reverse API release JAR includes the following runtime libraries:

- [Jackson](https://github.com/FasterXML/jackson) — Apache License 2.0
- [RE2/J](https://github.com/google/re2j) — BSD 3-Clause License

License and notice files supplied by runtime dependencies are retained under `META-INF` in the assembled JAR. This document is informational; the dependency distributions contain their authoritative license terms and notices.
