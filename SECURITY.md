# Security policy

## Supported versions

Security fixes are applied to the latest released version of Reverse API.

## Reporting a vulnerability

Please do not disclose vulnerabilities, credentials, captured traffic or target details in a public issue.

Use GitHub's private vulnerability reporting feature on the repository's **Security** page when it is available. If private reporting is unavailable, contact the maintainer through the GitHub profile before sharing sensitive details.

Include the affected version, impact, reproduction steps and a minimal sanitized example. You should receive an acknowledgement within seven days. Release timing depends on severity and the work required to produce and verify a fix.

Reverse API processes potentially hostile HTTP traffic. Reports involving parser behavior, resource exhaustion, unsafe export, credential disclosure or unexpected network activity are especially useful.
